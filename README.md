# CardVault

CardVault is a single-page Magic: The Gathering collection and play utility.

## Run locally

Open `index.html` in a modern browser. Collection data currently stays in that browser's local storage.

## Planned setup

- Configure Firebase Authentication for email and password sign-in.
- Store each user's collection in Firestore and sync it across devices.
- Add Android packaging (Capacitor) after choosing the app identifier and Firebase project.
- Optionally publish the web version with GitHub Pages.

Firebase is not configured in this starter yet. Do not put private service-account credentials in this repository. A Firebase web app configuration can be added after the Firebase project and security rules are prepared.
